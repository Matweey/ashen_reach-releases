# Пепельный Предел — версии

Здесь лежат собранные версии игры «Пепельный Предел». Код игры — в закрытом репозитории, а этот только раздаёт
сборки лаунчеру.

**Как играть:** скачай `Launcher.zip` из последней версии ([Releases](../../releases/latest)), распакуй куда угодно и
запусти `Launcher.exe`. Лаунчер сам скачивает последнюю версию игры, показывает, что нового, и открывает атлас
мира с картами и хроники.

## Как это работает

- `.github/workflows/build.yml` каждые 15 минут смотрит, сдвинулся ли `main` в `kamisama-nah/ashen_reach`. Если да —
  собирает игру (Godot 4.7.2, `--export-pack`), архив `docs/world` (атлас и хроники) и лаунчер и выпускает версию.
  «Что нового» — сообщения коммитов с прошлой версии.
- Нужен секрет `SOURCE_TOKEN`: токен GitHub, который может читать `kamisama-nah/ashen_reach` (вместе с LFS).
- Модели берутся из Git LFS с кэшем: скачивается только изменившееся, но первая сборка тянет всё (~1,6 ГБ) и тратит
  квоту LFS владельца закрытого репозитория.
- Собрать вручную: Actions → build → Run workflow (галочка «force» — даже без новых коммитов).
